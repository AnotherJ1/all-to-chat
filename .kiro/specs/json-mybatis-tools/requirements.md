# 需求：JSON格式化工具 + MyBatis日志转SQL工具

## 需求1：JSON格式化工具
**用户故事：** 作为开发者，我需要一个JSON格式化/压缩工具，方便快速查看和处理JSON数据。

### 验收标准：
- 左侧为JSON输入框（支持粘贴超长JSON）
- 右侧为格式化结果显示框（只读，带语法高亮）
- 中间操作按钮区：格式化、压缩、复制、清空
- 支持保存到浏览器本地存储（localStorage），可查看历史记录
- 超长JSON（>1MB）格式化时不阻塞UI（使用Web Worker或分片处理）
- 输入非法JSON时显示错误提示及错误位置
- 响应式布局，移动端上下排列

## 需求2：MyBatis日志转SQL工具
**用户故事：** 作为Java开发者，我需要将MyBatis控制台日志自动解析为可执行SQL。

### 验收标准：
- 粘贴MyBatis日志后自动识别并解析SQL
- 支持解析 `Preparing:` 和 `Parameters:` 两行格式
- 将 `?` 占位符替换为实际参数值（自动处理字符串引号）
- 解析完成后自动保存到浏览器本地存储
- 提供历史记录列表，可查看/删除历史
- 支持复制解析后的SQL
- 支持批量解析（多条SQL日志一次粘贴）
